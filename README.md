# Tic Tac Toe Game

A two-player Tic Tac Toe game built with HTML, CSS, and vanilla JavaScript as part of the Prodigy InfoTech Web Development internship tasks.

## Features

- Two-player gameplay (X and O)
- Detects all eight winning combinations
- Detects a draw when the board is full
- Tracks the number of wins for each player during the session
- Reset the board to start another round

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

No dependencies or build tools are required.

## Project Files

- `index.html` — game board, scoreboard, and controls
- `style.css` — visual styling
- `script.js` — turns, win detection, draw detection, and scores
