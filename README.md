# Tic Tac Toe Game

A responsive two-player Tic Tac Toe game made with HTML, CSS and vanilla JavaScript.

## Features
- Two-player X and O turns
- Win and draw detection
- Winning combination highlight
- Scoreboard for Player X, Player O and draws
- New round and reset scores controls
- Keyboard-accessible buttons and responsive layout

## Run locally
Open `index.html` in a modern browser. No installation or dependencies are required.

## Files
- `index.html` — game interface
- `style.css` — responsive styling
- `script.js` — game rules, turns and score tracking

## Deployment
Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**.
